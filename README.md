#  RAP 90s STORE

## Sobre o projeto

A **RAP 90s STORE** é um projeto de banco de dados inspirado na cultura Hip-Hop e no Rap dos anos 90. A proposta é representar o funcionamento de uma loja que comercializa produtos relacionados ao universo do rap, como camisetas, bonés e acessórios.

O projeto foi desenvolvido utilizando conceitos de modelagem de banco de dados e SQL.

## 🎯 Objetivo

Criar um banco de dados organizado para armazenar informações de clientes, funcionários, produtos e pedidos, permitindo o gerenciamento das operações da loja.

## 🗄️ Estrutura do banco de dados

O banco de dados possui cinco tabelas principais:

- **Clientes:** armazena os dados dos clientes.
- **Funcionários:** registra os funcionários da loja.
- **Produtos:** guarda informações dos produtos disponíveis.
- **Pedidos:** registra as compras realizadas.
- **Itens_Pedido:** relaciona os produtos com seus respectivos pedidos.

## 🔗 Relacionamentos

- Um cliente pode realizar vários pedidos.
- Um funcionário pode registrar vários pedidos.
- Um pedido pode possuir vários itens.
- Um produto pode aparecer em vários itens de pedidos.

## 🛠️ Tecnologias utilizadas

- SQL
- MySQL
- XAMPP
- phpMyAdmin

## 📂 Arquivo principal

`rap 90.SQL` — contém os comandos SQL para criar o banco de dados e suas tabelas.
