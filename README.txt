RAP 90s STORE — ENTREGA

Este pacote está dividido em três pastas:

1. beckend/ — código Python do back-end: classes POO, DAOs, rotas Flask, conexão MySQL e requirements.txt.
2. diagrama/ — modelos conceitual, lógico e físico do banco.
3. data base/ — arquivo SQL para criar o banco rap90s_store no MySQL/phpMyAdmin.

Para executar: consulte beckend/README.md.
